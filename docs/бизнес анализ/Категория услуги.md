# User Story

## Создание категории

**Верхнеуровневый обзор:** как администратор я хочу создать категорию услуги, чтобы использовать её для фильтрации услуг.

**Роль:** администратор.

**Предусловие:** администратор открыл интерфейс создания категории услуги.

**Основной сценарий:**

1. Администратор указывает название категории услуги.
2. Администратор сохраняет категорию услуги.
3. Система создает категорию услуги.

Критерии приемки: создана категория услуги с указанным названием; категория услуги доступна для привязки к услугам.

## Категория услуги

Категория услуги - справочная сущность, которая создается через админ. панель.

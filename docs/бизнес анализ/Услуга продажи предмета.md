## Создание и редактирование УПП

**Верхнеуровневый обзор:** как администратор я хочу создать или изменить УПП, чтобы предлагать клиентам готовые предметы на платформе.

**Роль:** администратор.

**Предусловие:** администратор открыл интерфейс создания или редактирования УПП.

**Бизнес-правила:**

- Название УПП обязательно и не должно превышать 250 символов.
- Описание УПП необязательно и не должно превышать 1500 символов.
- Базовая стоимость УПП обязательна.
- УПП должна содержать от одного до десяти медиафайлов.
- Доступные форматы медиафайлов: `media_formats`.
- Максимальный размер изображения: `image_media_size`.
- Максимальный размер видео: `video_media_size`.

**Основной сценарий:**

1. Администратор указывает или изменяет название УПП.
2. Администратор указывает или изменяет описание УПП при необходимости.
3. Администратор указывает или изменяет базовую стоимость УПП.
4. Администратор добавляет, удаляет или изменяет медиафайлы УПП.
5. Администратор добавляет, удаляет или изменяет [[Услуга#Привязка категории|категории УПП]].
6. Администратор при необходимости добавляет, удаляет или изменяет [[Услуга#Связывание с модификаторами|модификаторы УПП]].
7. Администратор сохраняет УПП.
8. Система создает или обновляет УПП.

Критерии приемки: УПП создана или обновлена с обязательным названием длиной не более 250 символов, описанием длиной не более 1500 символов при его наличии и обязательной базовой стоимостью; УПП содержит от одного до десяти медиафайлов; выбранные категории и модификаторы при их наличии сохранены в составе УПП.

## Удаление УПП

**Верхнеуровневый обзор:** как администратор я хочу удалить УПП, чтобы исключить ее из системы и списка доступных услуг.

**Роль:** администратор.

**Предусловие:** администратор открыл список УПП; в списке есть удаляемая УПП.

**Бизнес-правила:**

- Удаление УПП подчиняется [[Общие бизнес-правила#Подтверждение удаления|общему правилу подтверждения удаления]].
- При удалении УПП система удаляет входящие в ее состав копии модификаторов.
- Удаленная УПП исключается из списка активных услуг.

**Основной сценарий:**

1. Администратор выбирает УПП.
2. Администратор подтверждает удаление УПП.
3. Система удаляет выбранную УПП.
4. Система исключает УПП из списка активных услуг.

Критерии приемки: УПП и входящие в ее состав копии модификаторов удалены из системы; УПП отсутствует в списке активных услуг.

# Сущности
## УПП

УПП это одна из услуг на платформе, которая подразумевает продажу\перепродажу предметов клиентам, такая услуга не подразумевает какой-либо входной информации для индивидуализации выполнения, кроме модификаторов.

**Результатом выполнения** услуги является [[#Проданный предмет|проданный предмет]].

### Вопросы и несостыковки

1. **Проданные предметы удаляемой УПП.**

   Проданный предмет хранит идентификатор УПП, но поведение ранее созданных проданных предметов при удалении этой УПП не определено.

   **Вопрос:** должны ли проданные предметы сохранять связь с удаленной УПП, хранить снимок ее данных или удаляться вместе с УПП?

## УПП

| Название поля          | Описание поля                                          | Валидации                                                            |
| ---------------------- | ------------------------------------------------------ | -------------------------------------------------------------------- |
| Название               | Текстовое название продукта                            | Обязательно<br>Макс. 250 символов                                    |
| Описание               | Текстовое описание продукта                            | Максимум 1500 символов                                               |
| Категории              | Категории услуги                                       | [[Услуга#Привязка категории|Общие правила категорий]]                 |
| Стоимость              | Базовая стоимость услуги                               | Обязательно                                                          |
| Медиа файлы            | Фото/видео файлы. До 10 штук                           | Минимум 1<br>Форматы: `media_formats`<br>Максимальный размер изображения: `image_media_size`<br>Максимальный размер видео: `video_media_size` |
| Модификаторы           | Модификаторы, доступные для УПП                         |                                                                      |
| Значения модификаторов | Доступные значения каждого модификатора                |                                                                      |
**Проданный предмет**

| Название поля                  | Описание поля                                  | Валидации   |
| ------------------------------ | ---------------------------------------------- | ----------- |
| УПП                            | Идентификатор _УПП_                            | Обязательно |
| Значения модификаторов         | Выбранные пользователем значения модификаторов |             |
| Стоимость каждого модификатора | Стоимость каждого выбранного модификатора      |             |
| Конечная стоимость             | Автоматически рассчитанная стоимость           |             |
